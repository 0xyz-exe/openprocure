# Security Policy

OpenProcure takes application security and organizational data isolation seriously.

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability, please do NOT create a public issue. Instead, report it privately via GitHub Security Advisories or email security@openprocure.org.

Include:
- Type of vulnerability (e.g. IDOR, RBAC bypass, SQL injection, CSRF)
- Steps to reproduce
- Affected endpoints or models
- Potential impact
